02

Common formulation

The canonical method remains uniform-Euler velocity correction. Same-noise utility references and independent distribution targets have different roles.

Canonical FCT contract
ComponentDefinitionImplementation contract
Canonical updatexk+1 = xk + (1/N)[v₀(xk, k/N; c) + cφ(xk, k/N, c)]Correction is a velocity evaluated at the current state. Zero correction reproduces the same-N frozen Euler sampler.
Per-context matchingS = Σr βr[Σi≠j kr(aᵢ,aⱼ)/(2K(K−1)) − (1−ρ)Σi,m kr(aᵢ,bᵀₘ)/(KMT) − ρΣi,n kr(aᵢ,bᴳᵀₙ)/(KMGT)]K≥2 when matching is active. Differentiate both generated arguments, exclude self-pairs, apply weights once, and average contexts equally. Omit inactive sources.
Total objectiveJ = meancontexts[au meanstudents U + λS], with U = −R for maximized rewards.Training omits only the parameter-independent target-only term. Frozen targets remain independent of student noise.
Pairing identityMatching targets: independent draws. Paired fidelity reference: exact student noise and condition.Do not substitute a same-noise endpoint for an independent matching target. A paired reward is a different statistical role.
TerminologyFCT utility optimization uses pathwise differentiation of the finite sampler.Call it direct reward optimization when distinguishing it from likelihood-ratio / PPO / GRPO policy gradients.
External methodsRetain each baseline’s defining sampler, objective, regularizers and trainable parameterization.Uniform Euler and the Laplace kernel specify FCT. They are not imposed on competitors in ways that change the published algorithm.

07

Comparison and reporting rules

Preserve what defines each external algorithm. A common reward and evaluation protocol should not erase differences in training data, stochastic sampling, model capacity or auxiliary cost.

Fair comparison contract
DimensionRequired comparison ruleInterpretation / caveat
Backbone and conditioningSame checkpoint, decoder, resolution, clip duration, condition preprocessing and prompt set within a controlled comparison.Model family name alone is insufficient. Record exact model/config/revision hashes.
RewardShared scalar reward inputs and calibration within a comparison; retain algorithm-specific transforms and document them.If a baseline optimizes ImageReward/HPS instead of PickScore, those scores cease to be unoptimized metrics for that row.
Data regimeSeparate teacher-only, real-data-assisted and preference-pair comparisons.Preserve defining ReFL, DPO and adversarial losses. Removing them creates a named variant, not an unchanged reproduction.
Training budgetReport GPU-hours, student trajectories, reward evaluations, teacher calls and all auxiliary-model training.Equal optimizer updates alone is not equal compute. Include distillation cold starts and sequential continuation.
Trainable parametersReport corrector, LoRA, full-model and auxiliary parameter counts.Use native published parameterization for the external-method table; parameter-matched variants form a separate analysis.
Inference costActual network evaluations, CFG branches, correction calls, decoder/reward cost where relevant, latency and peak memory.Fused conditional/unconditional batches still represent two sample-equivalent backbone evaluations.
Comparison scopeFixed-length bidirectional video is the E4/E5 controlled scope.CausVid, Self-Forcing, causal-rCM and systems with attention/decoder/quantization changes belong to separate scope/cost references when those changes are enabled.
Checkpoint usePublic checkpoints can be system references; controlled reproduction requires matched provenance.Do not claim training-efficiency parity from inference-only checkpoints with unknown training cost.
ReportingPublish full curves, selected checkpoint rule, uncertainty and seed counts; preserve failed or incomplete runs.Predeclare repeated-condition generation and diversity estimators. Do not select a favorable metric or seed after seeing outcomes.
E6 utility remains a design proposal.

On RGB values in [0,1], define Charbonnier error as mean(√((prediction−GT)²+10⁻⁶)−10⁻³). The temporal term compares prediction and GT motion-aligned residuals using fixed GT flow and masks. Freeze positive calibration scales on training-only teacher outputs; reject degenerate scales. Use U = LPIPS + 0.1 C/sC + 0.1 T/sT initially, and retain LPIPS-only as a control. Coefficients, temporal alignment and calibration must be fixed before a formal run; they are not validated optima.

Verification and execution gates

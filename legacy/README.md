# Historical archive

`pre-canonical/` retains 19 files from commit
`35c0e1b5a0a32c39c27e1de4b608f44e36a2c8ae`, with their original relative paths.
Two historical Markdown files were removed at the user's request, and their
cross-reference was removed from the method summary. `inventory.json` records
the retained files' SHA256 hashes, removals, and the summary's original hash.

This archive is historical evidence, not an alternate supported implementation.
In particular, the post-step displacement and standalone next-state student do
not implement the canonical uniform-Euler velocity correction. Historical paired
teacher matching and auxiliary intermediate losses must not be relabeled as the
independent-target objective. Historical experimental claims are preserved as
reported, not revalidated or assigned to the new experiment matrix.

The active package and test discovery exclude this directory. Original packaging
and README files are retained here as well as rewritten at the repository root.
